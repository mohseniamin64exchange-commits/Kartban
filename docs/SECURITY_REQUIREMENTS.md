# CardYar security contract

- هیچ مجوز اینترنتی، تحلیل‌گر، گزارش‌گر خطا یا فونت آنلاین مجاز نیست.
- داده‌های عادی در پایگاه محلی و داده حساس کارت شخصی با AES-GCM رمز می‌شود.
- کلید اصلی در Android Keystore نگه‌داری و دسترسی به آن با احراز هویت محلی کنترل می‌شود.
- ورود اختیاری برنامه: رمز یا پترن و در صورت پشتیبانی اثر انگشت. اگر اطلاعات حساس ذخیره شده، حداقل یک روش قفل اجباری است.
- مقادیر حساس در متن واضح روی دیسک، لاگ، clipboard، state restoration یا crash message نوشته نشوند.
- فعال‌سازی نمایش حساس باید FLAG_SECURE را روشن کند و پنهان‌سازی آن را خاموش کند.
- clipboard فیلدهای عادی پس از مهلت کوتاه پاک شود.
- Android Auto Backup و device transfer برای داده برنامه غیرفعال است.
- پشتیبان محلی ابتدا سلامت داده را بررسی، سپس بسته نسخه‌دار را رمز و احراز اصالت می‌کند. بازیابی قبل از اعمال، رمزگشایی، امضا، نسخه schema و خلاصه را بررسی می‌کند.
- خروجی SMS و تصویر فقط نام بانک، صاحب کارت، شماره کارت، حساب و شبا دارد.
- راه فراموشی رمز هنوز تصمیم‌گیری نشده است؛ هیچ backdoor یا بازیابی ابری ساخته نشود.
